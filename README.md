# Bash--Phred-score
Στο script.sh προσπάθησα να εντοπίσω την κωδικοποίηση PHRED κάθε αρχείου FASTQ που παρήχθη από την εκτέλεση του bash.sh. Η λογική που ακολούθησα ήταν η ακόλουθη:
1) Αρχικά εντοπίζω με την χρήση της awk την τέταρτη γραμμή κάθε αρχείου που θα παράγεται από την εκτέλεση του script.sh. Κάθε FASTQ αρχείο αποτελείται από τετράδες γραμμών που αφορούν ξεχωριστά reads. Η τέταρτη γραμμή κάθε τετράδας αποτελεί το Phred score κάθε βάσης του read. Ελέγχοντας μόνο την τέταρτη γραμμή του πρώτου read, κι όχι την τέταρτη γραμμή κάθε read ενός αρχείου FASTQ, σκέφτηκα ότι θα αρκεί για να αντιστοιχήσω την κωδικοποίηση με Phred+33 ή Phred+64, διότι όλα τα reads ενός FASTQ έχουν παραχθεί από το ίδιο μηχάνημα αλληλούχησης.
2) Το αποτέλεσμα της awk δίνεται ως είσοδος στην grep. Δεδομένου ότι η έξοδος της awk αποτελεί μια γραμμή μόνο με χαρακτήρες ASCII, στόχος της grep είναι να αναζητήσει σε αυτή τους χαρακτήρες ASCII που βρίσκονται μεταξύ των ! και / (δηλαδή !, ", #, $, %, &, ', (, ), *, +, `, -, ., /). Οι χαρακτήρες αυτοί αντιστοιχούν σε score 33-47, οπότε δεν είναι δυνατό να εντοπιστούν σε αρχεία με κωδικοποίση Phred+64.
3) Αν η grep εντοπίσει έναν από τους παραπάνω χαρακτήρες, θα έχει ως exit code μηδέν. Συνεπώς, εντοπίζοντας τo μηδέν ως exit code, μπορώ να συμπεράνω ότι το συγκεκριμένο FASTQ αρχείο έχει κωδικοποίηση Phred+33. Εναλλακτικά, έχει κωδικοποίηση Phred+64.
